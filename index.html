Akselerasi Daya Saing Produk Belitung Melalui Kecerdasan Buatan (AI)

Produk UMKM di Kepulauan Belitung (seperti olahan lada/sahang, kerupuk kemplang, terasi/belacan, olahan kepiting, hingga kerajinan etnik) memiliki potensi pasar yang masif. Namun, pelaku usaha sering kali menghadapi kendala keterbatasan waktu, biaya produksi konten promosi, dan kemampuan merumuskan identitas merek yang kuat.

Program PKM ini menghadirkan transfer pengetahuan teknologi Artificial Intelligence (AI Generatif) yang mudah dipraktikkan langsung oleh pelaku UMKM hanya dengan smartphone, mulai dari perumusan *copywriting*, pembuatan visual kemasan, pemetaan target audiens, hingga penentuan *positioning* produk di pasar nasional.

Brand Awareness

Membantu UMKM memproduksi konten pemasaran konsisten & berkualitas tinggi dalam hitungan menit memanfaatkan AI.

Positioning Kuat

Menonjolkan keunikan autentik khas Belitung agar produk memiliki diferensiasi dan nilai jual lebih tinggi dibanding kompetitor.

Kurikulum Modul Pelatihan

Pilar Pelatihan Pemasaran Digital Berbasis AI

Dirancang sistematis agar mudah dipelajari oleh seluruh pelaku UMKM Belitung tanpa memerlukan latar belakang teknis yang rumit.

1. AI Copywriting & Caption Promosi

Teknik menyusun rumus *prompt* untuk menghasilkan deskripsi produk yang memikat di Shopee/Tokopedia, *storytelling* khas Belitung, dan caption Instagram/TikTok yang menjual.

2. Desain Visual & Foto Produk AI

Optimalisasi tool AI visual untuk menghapus background secara instan, membuat mockup katalog etalase profesional bertema eksotisme pantai Belitung, dan poster promosi.

3. Brand Positioning & Analisis Audiens

Pemanfaatan AI sebagai konsultan bisnis virtual untuk memetakan segmen pelanggan wisatawan vs pasar daring, menganalisis kompetitor, dan menentukan keunggulan unik (USP) produk.

Cara Menampilkan Buku Panduan PDF di GitHub

Langkah 1: Letakkan File PDF di Folder Repo

Buat folder docs di repositori GitHub Anda, lalu upload file PDF buku panduan (contoh: docs/buku-panduan-ai-belitung.pdf).

Langkah 2: Hubungkan Path File di JavaScript

Buka file index.html ini, pada variabel const documentsData ganti properti pdfUrl dengan nama file PDF Anda:

{
  id: "buku-panduan-ai",
  title: "Buku Panduan Pemasaran Digital Berbasis AI untuk UMKM Belitung",
  category: "panduan",
  desc: "Pedoman praktis penggunaan prompt AI untuk UMKM Belitung.",
  pdfUrl: "docs/Guide Book.pdf", // Path file Anda di repo
  pages: "58 Halaman",
  date: "Oktober 2024",
  badge: "Buku Utama"
}

Langkah 3: Commit & Push ke GitHub

Begitu Anda simpan dan commit ke branch main, GitHub Pages akan meng-update web secara otomatis dan file PDF Anda dapat dibaca langsung oleh siapapun!
